**This is a simple barcode scanner application built using TypeScript, React, Expo, and SQLite ***(Current tech stack is subject to change as this project is in the early stages)***. It allows users to scan barcodes using their device's camera and decode the information contained within the barcode. The information scanned will be saved to a list that can then be exported. The app will function completely offline. The application supports various barcode formats, including QR codes, Code 128, and EAN-13.**
